# anyview-automation

广东工业大学 AnyView 编程练习自动化工作流：章节筛选、服务端通过状态复核、停止续跑和逐题结果导出。

当前实现范围为第一至第五章。运行使用自己的已登录学生页面和自己有权使用的题解文件。框架以 MIT 许可公开，**不包含题解库、账号、密码、认证 token 或实际学生作业记录**。框架许可不授予学校课程材料或外部题解的再分发权。

## 功能

- 读取实际课程列表，选择课程后预览范围内题目。
- 按题号顺序处理，服务端已经通过的题不重复提交。
- 每题核对题号、章节、语言信息，编译后调用判题服务。
- 只有判题 `passed === true` 且最新目录 `pass === true` 才记录本轮通过。
- 编译失败、判题失败、会话异常或结果不明时暂停，保留逐题阶段。
- 未知写入结果不会自动重发；重启后先查询目录对账。
- 浏览器 Web Locks 阻止多标签页并发；支持停止和 JSON 报告导出。
- 认证仅在当前页面内存里使用；不读取 Cookie、不另行登录、不上传到其他服务。

## 本地构建

需要 Python 3.10+。仅测试需要 Node.js 20+，运行脚本无需 npm 包。

```sh
python3 import_bank.py /absolute/path/to/your-answer-archive.zip
python3 build.py
```

导入器只读取 `DC01` 至 `DC05` 的 `module.exports = "..."` JSON 字符串，不执行压缩包内的 JavaScript、Python、启动器或二进制。题解导入到 Git 忽略的 `local/bank.json`，最终脚本生成到 Git 忽略的 `dist/anyview-runner.js`。也可以直接提供自己的 JSON 对象，题号为键、完整 C 代码为值：

```sh
python3 build.py --bank /absolute/path/to/your-bank.json
```

## 在 Ego Lite 中使用

1. 在 AnyView 官方学生页面手动登录，打开目标编程课程。
2. 审阅生成的 `dist/anyview-runner.js`，在该页面的开发者工具 Console 或 Snippets 中运行。也可在 Ego Lite 打开本地 `dist/install.html`，把其中的启动器链接拖到书签栏，再切回 AnyView 点击书签。浏览器如果要求人工处理粘贴或权限提示，由用户本人完成。
3. 脚本会显示控制面板。在学校原页面正常点击一次返回、课程或章节，使脚本连接当前会话；不需要把密码交给脚本。
4. 点击「读取课程与目录」，核对课程和题目数量。
5. 点击「先验证 DC01PE21」。确认单题判题和目录通过后，再点击「开始第一至第五章」。
6. 可以随时点「停止」；当前请求的结果会先落盘。结束后点「导出结果」。

页面刷新后需要重新运行脚本。相同课程的逐题记录保存在该浏览器的本站 localStorage 中；不保存认证信息。多个学生共用同一浏览器配置时，不明确记录会保守阻止重发，应先人工核对。完整题解会包含在生成的私有运行文件中，公开分享前需独立确认权利。

## 失败与续跑

`compile_failed` / `failed`：检查输出和题解，修正本地题解、重新构建，刷新学校页面并重新加载新脚本后再运行。直接重复点击旧书签仍然使用该书签内的旧题解；重新构建后需重新添加生成的新启动器书签。

`uncertain` / 上次停在 `compiling` 或 `judging`：下次先读目录。如果服务端已通过则跳过，否则保持暂停，避免重复未知提交。导出报告并人工核实请求结果后再处理；框架不提供一键抹掉不明结果的操作。

当前保守实现每题每次启动最多一次判题 POST，不通过后暂停。参考包关于服务端首次运行可能使用旧代码的描述尚需实际验证，框架不会据此盲目反复提交。

## 验证

```sh
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
python3 build.py
node --check dist/anyview-runner.js
```

离线测试验证状态机与边界，不代表学校真实判题通过。真实验收以学校最新目录为准；运行记录应留在本地，不提交公共仓库。

## 结构

| 文件 | 用途 |
| --- | --- |
| `src/core.mjs` | 可测试的逐题状态机 |
| `src/browser.js` | 同源传输、页面面板和会话内存连接 |
| `import_bank.py` | 只按数据导入私有题解 |
| `build.py` | 生成独立运行脚本 |
| `tests/` | 无网络的状态机、导入器验证 |
| `docs/proposal.md` | 实施范围与验收条件 |
| `THIRD_PARTY_NOTICES.md` | 参考材料与权利边界 |
